# py-image-manager
> image deduplicator

Small project to keep your backup images free from duplicates, keeping intact your save structure.  

If, like me, you're tired of checking your pictures one by one and deleting duplicates while linking the correct file to the folder,  
**waste your time no further**, this project will help you deleting duplicates and creating symlinks to one single file, reducing wasted space in your backup drive.
